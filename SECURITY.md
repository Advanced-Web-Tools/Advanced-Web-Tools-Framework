# Security Policy

## Supported Versions

Security fixes are provided only for the latest stable release of AWT Framework. If you use an older version, update to the latest stable release.

| Version | Security Updates |
| ------- | ---------------- |
| Latest stable release | ✅ |
| Older releases | ❌ |
| Development versions | ❌ |

## Reporting a Vulnerability

Please report suspected vulnerabilities privately. Do not open a public issue or disclose exploit details before a fix is available.

Use GitHub’s **Report a vulnerability** option in the repository’s **Security** tab. If private reporting is unavailable, contact a maintainer to request a private reporting channel without sharing sensitive details publicly.

Include the following information where relevant:

- AWT Framework version and affected component.
- PHP version, operating system, and web server.
- Installed packages, plugins, and themes, including their versions.
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue and any required configuration.
- A minimal proof of concept, code snippets, or screenshots.

Remove passwords, API keys, tokens, personal data, and other secrets from your report.

## Review and Disclosure

Reports are reviewed to confirm the issue, assess its impact, and determine an appropriate fix. Additional information may be requested during this process.

Please coordinate public disclosure with the maintainers so users have an opportunity to update before technical details are published.

## Third-Party Packages

For vulnerabilities in independently maintained packages, plugins, or themes, contact their maintainers directly. If the issue also affects AWT Framework, report it here as well.
